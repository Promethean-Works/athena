Athena is a self-hosted control panel for Linux, macOS and Windows. Install apps, manage files and cloud storage, schedule backups, and let an AI assistant do the chores, with your approval first.

One dashboard, every system

Athena detects what your machine has (a container runtime, a package manager, rclone, a tunnel tool) and shows only what works there. No dead buttons.

Cross-platform

Linux with systemd, macOS with launchd and Homebrew, and Windows. One dashboard everywhere.

Private by default

Runs on your hardware. The assistant can use a local model so nothing leaves the machine. Secrets are encrypted at rest.

Safe to hand over

The assistant asks before it changes anything, and every admin action goes to an audit log.

Open source only

Apache-2.0, built on open-source dependencies. Self-update and a one-line installer included.

Everything a home server needs

One place for the work you would otherwise do over SSH.

An app store with about 190 apps

Install Jellyfin, Immich, Home Assistant, Grafana, Nextcloud and more with a short form. Or deploy your own from a compose.yaml or a docker run command.

  • Uses Docker Engine, Colima, WSL2 or Podman, whichever you have
  • Add your own catalogs from a Git repository or URL
  • Apps that don't fit your CPU are hidden

Install in one line

The installer checks the download against the release checksums, sets up a container runtime where it can, and starts Athena automatically at boot.

Linux and macOS

curl -fsSL https://github.com/Promethean-Works/athena/releases/latest/download/install.sh | bash

Windows (PowerShell)

irm https://github.com/Promethean-Works/athena/releases/latest/download/install.ps1 | iex

Then open http://<your-server-ip>:8420. The first visit asks you to create the administrator account.

Upgrade by running the same command again; your data is kept. Uninstall with --uninstall, and add --purge to delete the data too. Run the script with --help to see every option.

Requirements

SystemsLinux (systemd), macOS (launchd, Homebrew) and Windows.
CPUs64-bit amd64 or arm64, including a Raspberry Pi 4 or 5 on 64-bit Raspberry Pi OS. 32-bit systems are refused.
Container runtimeInstalled for you on Linux (Docker Engine) and macOS (Colima). On Windows bring Docker Engine in WSL2, Podman or Rancher Desktop.
PythonNothing to do. The installer adds uv, which provides it.
macOS noteRun the installer as your normal user, not root.

Questions

Is Athena free?

Yes. It is open source under the Apache-2.0 license and uses open-source dependencies only.

Does my data leave my server?

No, unless you choose it: a cloud AI model, a cloud backup destination or a tunnel. With a local Ollama or llama.cpp model and a local backup destination, nothing leaves the machine.

Can the assistant break my server?

It asks for your approval before it changes anything, and its shell tool is off by default. Every action is in the audit log. Still read each approval card before you accept it.

Is it safe to put on the internet?

Don't forward port 8420. Use a tunnel (Cloudflare, Tailscale or ngrok) and HTTPS, and a long administrator password.

Do I need Docker?

For apps, yes: a container runtime. Athena installs one on Linux and macOS. Files, packages, terminal, automation and the assistant work without it.

What isn't tested yet?

Athena is at a 0.1.0 release candidate. Package install on Linux was checked with apt only (dnf, pacman, zypper, apk and the Windows managers are untested on real hosts); Let's Encrypt, named tunnels, ngrok and Tailscale are unverified; and the assistant's browser tool is off. The README keeps the full list.

How do I get help or report a bug?

Use Send feedback in the Athena sidebar, or open an issue on GitHub.
