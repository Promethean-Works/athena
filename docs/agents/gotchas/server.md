# Gotchas: Server (Python)

- `athena openapi` must not create the real data dir. It builds the app against a temp dir, and a test enforces this.
- SQLite runs in WAL mode. A test that reads `athena.db` directly misses rows still in `athena.db-wal`, so query through SQLAlchemy.
- `ruff --fix` can delete an import it thinks is unused when the name is shadowed. Use an aliased import.
- Mutable class attributes trip RUF012. Use tuples or `ClassVar`.
- The capability status type is `Status` (`athena/platform/`), not `CapabilityStatus`. <!-- docs-check: ignore -->
- Open SSE streams never end on their own. uvicorn's `timeout_graceful_shutdown` (5 s, `SHUTDOWN_GRACE_SECONDS` in `cli.py`) is what lets the service stop with a dashboard open. Keep it.
- Every compose command needs `env=store.env(name)`, not only deploy. Stop, restart and remove once failed for apps using `${ATHENA_APP_DATA}`.
- Compose YAML is YAML 1.2: `yes` is a string, not `true`. The CasaOS importer parses it the same way (one of 182 apps broke on this).
- Terminal: don't use `pty.fork()` or ptyprocess in the multi-threaded server; they can deadlock (Python 3.12+ warns). Use the stdlib pty with `Popen(start_new_session=True)` and the `TIOCSCTTY` shim in `athena/terminal/pty.py`.
- `require_user` can't protect WebSockets. The terminal checks the cookie itself and takes the CSRF token in the first message (see the top of `api/terminal.py`).
- wsgidav: a DELETE on a collection whose `delete()` refuses falls back to deleting every member one by one. That emptied a whole location. Refuse such requests in `handle_delete` / `handle_copy` / `handle_move` before wsgidav gets there, and test it.
- Tests that need a CLI to be _absent_ must really hide it from PATH. A test passed on every machine with `docker` and only failed on macOS CI, which has none. Run such tests with the tool removed from PATH.
- The release wheel must include the catalog (`athena/catalog_builtin`) and the web export. Once it shipped without the catalog, and the store was empty. `build-wheel.sh` now fails if either is missing.
- Docker Hub's tag API (`hub.docker.com/v2/repositories/.../tags/<tag>`) allows about 180 requests a minute per IP and answers 429 with `retry-after: 60`. A full `athena.catalog.image_platforms` run uses about 140, so back-to-back runs fail; the script waits out 429s, but run one at a time. It uses that API instead of `registry-1.docker.io` because manifest GETs there count against the pull limit.
- HTTPS runs a second `uvicorn.Server` inside the app (`athena/https/manager.py`). It must use `lifespan="off"` (or the scheduler and job worker start twice), override `capture_signals` (or it steals SIGINT/SIGTERM from the main server), and get a socket we bound ourselves (uvicorn calls `sys.exit` when it can't bind, which would kill the whole server). A renewed certificate goes into the live `SSLContext` with `load_cert_chain`; no restart.
- The HTTP → HTTPS redirect is a 307, not 308: browsers cache 308 as permanent, so turning HTTPS off would leave them stuck. It skips requests carrying `X-Forwarded-*`, because uvicorn's proxy-header handling has already replaced a tunnel's loopback address with the visitor's.
- On macOS, `SO_REUSEADDR` lets Athena bind `0.0.0.0:8443` while another program holds `127.0.0.1:8443`, so the HTTPS "port in use" check misses that case there; Linux and Windows refuse.
- Tunnel clients (cloudflared, ngrok) must outlive the job that starts them, whose event loop closes when it ends. `tunnel/process.py` runs them with `Popen` and a reader thread, not an asyncio subprocess, and the lifespan calls each provider's `shutdown()`. Earlier `start()` returned a placeholder URL and launched nothing, so the status always said stopped.
- A fresh `trycloudflare.com` URL can fail to resolve for a minute: the local resolver caches the "not found" it got before the record existed. Check with `dig @1.1.1.1` and `curl --resolve` before calling the tunnel broken.
- Never await the HTTPS listener's shutdown from a request handler: the request may have come over that listener, and uvicorn's graceful shutdown waits for open requests, so it waits on itself. `HttpsManager._stop_in_background` stops it after the response.
- HTTPS: CI's Pebble runs with `PEBBLE_VA_ALWAYS_VALID=1`, so it never connects to port 80. Real HTTP-01 validation was only checked in a Lima VM (Pebble with `httpPort: 80` plus `pebble-challtestsrv` as its DNS; recipe in the `athena-host-test` skill). Don't read the CI test as proof that port 80 works.
- lego logs in logfmt: the useful part of a failure is the `error="…"` value with `\"` escapes, at the end of a very long line. `_lego_failure` (`https/manager.py`) pulls it out; slicing the raw line once showed `rror="renew…` on the Settings page.
- The HTTP-01 job checks port 80 itself before running lego (`port80_problem`), except when `ATHENA_ACME_HTTP_ADDRESS` moves the challenge elsewhere (tests). Without the check, a busy port 80 surfaced only as lego's `bind: address already in use` buried in the log.
- Tests must use `tmp_path` for the data dir, never a fixed `/tmp/...` path: worktrees share `/tmp`, and a DB migrated by another branch (a revision this branch doesn't have) breaks the test with alembic's "Can't locate revision".
- `athena serve` (without `--reload`) is a supervisor: it spawns a child `athena serve` with `ATHENA_SERVE_CHILD=1` and restarts it on exit code 75 (`restart.RESTART_EXIT_CODE`). A test that calls `main(["serve", ...])` must set that env var and stub `uvicorn.Server.run`, or it starts a real server in a subprocess and hangs. The child also stops by itself when its parent disappears (`_stop_with_parent`), because Windows can't forward SIGTERM to it. <!-- docs-check: ignore -->
- `monkeypatch.setattr(<module>.subprocess, "run", fake)` patches the shared `subprocess` module for the whole process, not just that module. Background threads still running from earlier tests (the monitor's stats sampler runs `powermetrics` on macOS) then hit the fake, land in its recorded calls and get its return value. Fake only the test's own thread (`threading.get_ident()`) and pass other threads to the real `run`, as `tests/test_tunnel_service.py`'s `host` fixture does.
- Anything an unauthenticated caller controls (a bearer token, a cookie) must go to `hmac.compare_digest` as bytes: a `str` with non-ASCII characters raises `TypeError` and becomes a 500. Starlette passes non-ASCII headers and cookies through. In tests send them as bytes (`httpx2` refuses non-ASCII `str` headers).
- `LoginThrottle` is keyed per client IP and per account (`user:<name>`). A success on one account must never reset another's count, or a user with any valid account can guess the admin's password between their own sign-ins. `retry_after` must not create entries (memory growth from random usernames).
- `tarfile.extractall` needs `filter="data"` on Python 3.13 (the default still trusts the archive).
- A plain user can reach a job only if its route passes `user_visible=True` to `jobs.start` (app start/stop/restart and file transfers do). Any other job, including installs and restores, is admin-only and reads as 404 to everyone else; a new route open to plain users that starts a job needs the flag.
- Outside MCP tools (`assistant/mcp.py:guard`) need an approval card unless the server sets `readOnlyHint`; helper agents get only the read-only ones. Never add an MCP toolset to an agent without `guard`. The approval card's fallback sentence is in `chat._approvals_out`.
- A catalog app whose compose is `privileged`, has `SYS_ADMIN`, uses host networking or mounts the Docker socket needs an `x-athena.notes` warning (`test_apps_that_ask_for_elevated_access_say_so`).
- Anything Athena downloads and runs needs a checksum from a second place (see `tunnel/verify.py`, `downloads.py`). If the vendor publishes none (ngrok), install through a package manager instead.
- A systemd `ExecStart=` expands `%` and `$` even in quotes; `service/platforms.py:_systemd_quote` doubles them.
- Test `jobs.start` from a sync test through `client.portal.call(lambda: jobs.start(...))`; there is no running loop in the test body.
